# GuardFines

Плагин штрафов для Paper 1.21.11 (Java 21).

## Команды

- `/fine give <игрок> <сумма> <срок> [причина]` — выдать штраф. Срок: `30m`, `12h`, `7d`, `2w`.
- `/fine list` — GUI всех открытых штрафов, выданных вами. Администратор видит все.
- `/fine paid <id>` — подтвердить выплату.
- `/fine cancel <id>` — отменить штраф.
- `/fine reload` — перечитать `config.yml` (только администратор).

В GUI: ЛКМ подтверждает выплату, ПКМ отменяет штраф.

## Права

- `guardfines.use` — использование системы (по умолчанию только операторы).
- `guardfines.admin` — просмотр и управление всеми штрафами, перезагрузка.

## Установка

1. Соберите проект командой `mvn clean package` на Java 21.
2. Скопируйте `target/GuardFines-1.0.0.jar` в папку `plugins` сервера.
3. Перезапустите сервер.

Данные создаются в `plugins/GuardFines/fines.yml`. Каждая запись хранит статус `UNPAID`, `OVERDUE`, `PAID` или `CANCELLED` и русское имя статуса.
